# The Slack Book: Slackware 15 Edition

An updated edition of the Slackware guide, revised for Slackware 15.0.

*This is unofficial. It is not published or endorsed by Slackware Linux, Inc. or Patrick Volderking.*


This repository is a fork of the *Revised Slackware Book Project*(<https://www.slackbook.org/>), a rewrite of *Slackware Linux Essentials* that was left unfinished.


Forked from <https://github.com/slackwarecn/slackbook> at commit `7151c23` (2012-10-03).


## Build


```
make
```

Building requires `xsltproc`, the DocBook XSL spreadsheets, the DocBook XML 4.5 DTD, and ImageMagick.
